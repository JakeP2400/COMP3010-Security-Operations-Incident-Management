## Installation
For the Splunk installation, a combination of the resources provided through the DLE and the Splunk website (splunk.com) provided very useful. I opted to run my splunk instance on a Ubuntu 24.x.x machine which ran on a desktop device. By doing this, I was able to access my splunk instance from various devices on a local network, allowing for me to use personal laptops and other desktop devices for querying the data set and developing my answers to the questions. This type of deployment is emulating what would be a single-instance deployment on an enterprise environment, meaning the one instance handles processing data, indexing and searching, as opposed to the alternative which is distributed deployment. This type of deployment is geared towards larger environments which have more machines, more data and more users who may use the service. Typically with this style of deployment, each instance would handle a specialised task to manage one of the three main functions being:
* Data Input Tier
* Indexer Tier
* Search management Tier

https://help.splunk.com/en/splunk-enterprise/get-started/overview/9.4/about-splunk-enterprise/about-splunk-enterprise-deployments

Splunk uses search processing language (SPL), which is a properietary language uses for searching, filtering and displaying data (https://www.splunk.com/en_us/blog/learn/what-splunk-does.html).

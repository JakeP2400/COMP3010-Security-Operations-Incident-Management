Question 1: List out the IAM users that accessed an AWS service (successfully or unsuccessfully) in Frothly's AWS environment?
AWS IAM (Indentiy and Access Management) is a web service with the goal of assisting in controlling access to AWS resources (https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction.html). With Frothly being the company in which we are investigating on behalf of, we can deduce that Frothly is using cloud infrastructure. 
As IAM is an AWS service, we can start by using the "aws:cloudtrail" as cloudtrail is a service which can be used for auditing, govenrnance and compliance of AWS accounts. (https://docs.aws.amazon.com/awscloudtrail/latest/userguide/cloudtrail-user-guide.html). By searching through the fields provided within splunk, we cna see that the "userIDentity.userName" field contains the users which accessed an AWS service. 
Alternatively, the command "index=botsv3 sourcetype="aws:cloudtrail" | stats count by userIdentity.userName" shows the users within the "Statistics" tab. This confirms to us that the four IAM users are bstoll,btun,splunk_access,web_admin.
